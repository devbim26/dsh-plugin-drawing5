# Чертежи дома 3.4 «Северный берег»

Плагин подключает к агенту альбом чертежей проекта **21.08/2025-7.3-АР**
(Объект: Дом 3.4 «Северный берег», квартал 1). После установки вы просто
спрашиваете — агент сам найдёт ответ в документации.

## Что умеет

- **Отвечает на вопросы по загруженной документации** — по тексту,
  таблицам (ведомости, спецификации, экспликации) и пояснениям.
- **Проводит экспертизу по обычному текстовому запросу.** Например:
  «как устроена калитка на кровле», «из чего стена», «кто подписал
  лист 12», «сколько листов в комплекте».
- **Показывает части чертежа.** В ответе могут быть фрагменты графики
  (планы, узлы, разрезы) и ссылки на страницы альбома.
- **Ищет по всему альбому**, а не по одному листу: марки, помещения,
  конструкции, примечания.

Просто пишите вопрос по-человечески. Агент сам найдёт нужные листы,
прочтёт штампы и таблицы и покажет, где что смотреть.

## Установка

1. **Plugins → Add plugin** → вставьте ссылку, которую вам выдали.
2. **Установить** → перезапустите DeepSeek Harness.
3. Если вам выдали токен отдельно (а не персональную ссылку):

   ```bat
   setx DRAWING5_API_KEY <ваш токен>
   ```

   и снова перезапустите приложение.

Персональная ссылка с уже вшитым токеном — шаг 3 не нужен.

## Если не работает

| Что видите | Что делать |
|---|---|
| Агент не отвечает по чертежам | Перезапустите DeepSeek Harness |
| «server is disconnected» | Сервер временно недоступен — попробуйте позже или напишите владельцу |
| Просит токен / ошибка доступа | Проверьте, что вставили свою ссылку целиком |

Токен и ссылку выдаёт владелец. Вопросы по установке — к нему.
