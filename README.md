# drawing5 — чертежи в DeepSeek Harness

Плагин подключает облачный MCP-сервер **drawing5**. После установки и
перезапуска DSH в модели появляются инструменты `mcp__drawing5__*`:
навигация по комплектам чертежей, поиск по чертежу, листы, штампы,
картинки листов, загрузка PDF.

Python и правка YAML не нужны: плагин сам добавляет MCP-клиента.

## Установка

1. **Plugins → Add plugin** → вставьте ссылку (или имя пакета / путь).
2. **Установить** → перезапустите DSH.
3. Если токен не вшит в вашу сборку, задайте его один раз и снова
   перезапустите DSH:

   ```bat
   setx DRAWING5_API_KEY <ваш токен>
   setx DRAWING5_SERVER_URL https://drawing5.dev-bim.com
   ```

   `DRAWING5_SERVER_URL` — без `/mcp`. Персональная ссылка с вшитым
   токеном: `setx` не нужен.

## Что умеет агент

Типичный сценарий — агент проведёт сам:

1. `list_developments` → `list_houses` — найти дом.
2. `list_documents` — что уже загружено; если комплекта нет — `upload_pdf`.
3. `list_sheets` → `search` / `get_sheet` / `get_sheet_images`.

Проверка подключения: попросите агента вызвать `mcp__drawing5__get_health`.

## Если не работает

| Симптом | Что делать |
|---|---|
| Инструментов нет | Перезапустите DSH после установки |
| `server is disconnected` | Сервер не запущен или токен неверный |
| 401 | Не задан `DRAWING5_API_KEY` |

Персональную ссылку и токен выдаёт владелец сервера.
